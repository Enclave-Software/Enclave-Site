# Project Enclave

## Intro

[Project Enclave](https://projectenclave.dev) is a hobby project by a student in Class 9, so please do not expect it to be perfectly maintained. Even so, I will still try my best to improve it over time.

This project was created because of the issues affecting my state. For example, internet shutdowns can make services such as UPI and WhatsApp unreliable or unusable.

The mission of this project is to reduce single points of failure and allow people to connect, communicate, and do what they want more freely.

Big thanks to my classmates, GitHub and [Hackclub](https://hackclub.com) for helping me with this.

## Status

In development and testing. Functional versions have been distributed for testing to limited people.

## Goals

- Create a way for people to communicate without relying on the **Internet** (inspired by WhatsApp and Telegram)
- Allow people to build organised communities (inspired by Discord and Telegram)
- Let people create blogs (inspired by Tumblr)
- Let people create and host websites (inspired by Tor-style self-hosting and distributed access)
- Reduce dependence on the **Internet** and **central services**, and shift toward self-hosted and distributed systems
